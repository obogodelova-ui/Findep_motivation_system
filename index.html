Motivation Engine — создание системы мотивации

Что вводим: бизнес → функция → роль → результаты → архитектура дохода → KPI → экономический эффект → контроль.

Что получим: карточку сотрудника, резюме CFO, экономическую эффективность для компании, расчётный паспорт, QA-отчёт и карту мотивации функции.

Если после открытия файла остаётся только этот информационный экран, встроенный просмотрщик не исполняет локальный JavaScript. Откройте index.html в Safari / Chrome либо разместите файл как обычную веб-страницу. Данные и расчёты выполняются локально, сервер не требуется.
